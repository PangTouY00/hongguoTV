# hongguoMac 0.3.1

版本：0.3.1（build 12） · Apple Silicon · macOS 13+

本次更新在 0.3.0 基础上新增评论和真实时间轴弹幕，并修复全屏播放问题。

- 本集评论支持下滑连续加载，也可点击“加载更多”；自动去重，加载失败保留已有内容并可重试。
- 评论显示头像、作者、日期和只读赞数，支持对已加载内容筛选、排序和复制。
- 新增整剧剧评的官网公开节选，可打开或复制官方页面链接。
- 新增真实时间轴弹幕，支持开关记忆、失败重试，并与暂停、拖动和倍速同步。
- 改善弹幕文字清晰度和移动连续性，增大字体、增加描边并放慢滚动。
- 修复主窗口已全屏时，再点击视频全屏无法展开的问题。

## 安装与更新

下载 `hongguoMac-arm64-0.3.1.zip`，退出旧版应用，解压后将 `hongguoMac.app` 替换到“应用程序”。自带 Java 运行环境。本机收藏、历史和钥匙串登录态沿用原路径；安装包不包含账号登录态。

应用内下载更新后仍需手动退出、解压并替换。当前使用本机临时签名，尚未经过 Apple 公证。

## 当前范围

本集评论可以连续加载；整剧剧评仍为官网节选。发送、回复及点赞操作尚未接入，赞数仅供查看。接口可用性取决于源站。
