红果 TV 0.1.13 更新说明

- 新增离线缓存：选集面板可以「缓存本集」「缓存全部」，剧集详情页有「缓存全部 N 集」，播放页「播放设置 → 缓存管理」能删除单集、清空全部、停止队列，并显示已缓存集数、占用与剩余空间。
- 集数上直接画缓存状态：`✓` 已缓存、`…` 排队中、百分比、失败；播放界面在清晰度后标注「本地缓存」。
- 缓存文件存的是播放器实际消费的字节（改写过的容器索引加已解密的样本），离线播放不需要网络、不需要重新取址、不需要密钥与解密，也不受播放地址签名过期与限流影响。
- 缓存键是分集 id 加清晰度，不是播放地址哈希；下载一次只跑一集，中断后下次点同一集接着写；空间不够时当场拒绝并给出剩余 MB。缓存存在应用自己的目录，不需要存储权限，卸载即清。
- 自动化检查：`:core:test` 251 项全过，新增 18 项覆盖落盘、分块、续传、取消、删除、清空、空间判断与多档选择，另有一条端到端确认缓存里的字节与在线播放时逐段一致、且已是可解码索引。
- 本次只发 Android 6.0+ 一个包（versionName 0.1.13 / versionCode 54）；`android44-support` 那条线没有离线缓存，继续单独验证，验收后另行发版。
- 包名与签名不变，已装 0.1.12 可直接覆盖安装，本机收藏与观看进度保留。
- 未验证：实际电视上的下载速度、离线播放连续性与遥控器手感需装机验收；缓存整部剧期间正在在线播放的那一集可能缓冲更慢。

完整更新日志见本条 Release 的正文与 release-notes.md 附件。
