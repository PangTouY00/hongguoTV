# TV 评论与弹幕调试

当前正式版本为 0.1.2，下一次正式发布为 0.1.3。本次调试 versionName 维持 0.1.2，versionCode 维持 43；不生成或替换正式更新清单。

正式播放页按 ↑ 打开“更多”，进入“评论”或“弹幕设置”。评论面板支持上下方向键浏览、到底继续加载、手动加载更多和失败重试，返回键关闭面板；播放继续。普通评论匿名读取 App 接口，整剧剧评标明官网节选。点赞数量只读，没有发送或回复按钮。

弹幕使用真实毫秒时间轴，在原生 Canvas 上逐帧绘制；默认两行、24dp、慢速。设置中可切换开关、字号、速度和密度，保存在本机。暂停时冻结，拖动后按目标时间段读取，切集、后台和退出清理旧请求与内容。第一版入口位于正式播放页，首页首集试播暂未接入。

评论、时间轴弹幕、签名及有界响应读取位于 core，Mac 后端通过别名复用，TV 不运行 Java 回环服务。读取不使用账号 cookie，不涉及账号写操作。

自动检查：`:core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`。Robolectric 在 API 23 与 API 26 验证评论加载、去重、焦点恢复、设置保存和签名。实际 TV 遥控器布局、弹幕流畅度、暂停/拖动/倍速及自动下一集由用户手动验收；不自动安装或操作模拟器。

详情页也提供本集评论入口。常见表情标签使用随包分发的通用表情图片，避免 Android 6 字库缺失；未识别的标签保留原文。正文增加行距，详情页与播放页共用评论面板。

详情页移除重复选集按钮，主操作仅播放与本集评论，收藏和简介为次级操作。评论按整条卡片聚焦，元信息与正文分层；追加保持阅读位置，关闭全文和面板恢复原焦点。

首页效率调试：播放器优先消耗已有开头缓存，不为凑满网络分块而阻塞首读；后续作品预加载等待当前视频至少 3 秒缓冲。日志只记录推荐请求、播放地址和媒体索引耗时，不含账号或完整媒体地址。实际首帧耗时仍需电视端对比。

设置精简：移除手机备份恢复、恢复隐藏推荐及空的数据管理分组。保留账号登录、云端继续观看、刷新账号记录、退出及同步状态，不清除已有本机数据。
