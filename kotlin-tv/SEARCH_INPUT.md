# 搜索输入验证说明

分支 `feature-search-input`；测试版 `0.0.7-search-input`，内部版本号 23；Android 6+。

## 局域网扫码

原先只从 activeNetwork 取第一个 IPv4 地址，且要求默认网络直接声明 Wi-Fi 或网线。VPN 默认网络和多网卡可能导致找不到或选错地址。

现在枚举系统可见的 Wi-Fi、网线网络，排除 VPN，优先当前网络；旧电视固件缺少底层网络资料时，再枚举符合 Wi-Fi/网线接口名称的有效网卡。只选私有 IPv4，去重，排除回环、IPv6、链路本地和公网地址。二维码服务器绑定所选地址，可切换其他候选地址。只有真正访问携带有效临时口令的输入页时，才显示手机已连接。

二维码仍是局域网 HTTP 地址，不支持移动数据跨网连接。路由器设备隔离、电脑模拟器 NAT、防火墙或特殊 VPN 路由不能靠枚举地址解决。连接失败时需要用户反馈二维码显示的网络地址及手机浏览器错误，不能只凭自动化测试声称真实网络已修好。

保留原有 5 分钟、一次性口令、来源检查和 80 字符输入限制。关闭、切换窗口均释放旧服务器，避免延迟的 OnDismiss 错关新会话或遗留旧会话。连接帮助提供重新生成入口。手机发送后继续执行全片库搜索。

## 语音

搜索页调用系统 ACTION_RECOGNIZE_SPEECH 识别界面，请求中文和自由文本结果。识别活动由系统或已安装的识别服务实现，由该活动负责麦克风访问；本应用只接收文本，不申请自身录音权限，不持续录音。清单补充活动可见性 queries 兼容新版 Android。

识别文字填入搜索框，不自动提交；取消保留原输入。无识别活动、启动被拒绝、空结果均给出说明。识别结果限制 80 字符并拒绝控制字符。调用外部识别界面导致页面停止再返回时，保留搜索草稿。

是否识别中文、遥控器麦克风能否被第三方识别活动使用、是否需要网络，由设备的识别服务决定。仅有麦克风不代表具备识别服务。不存在识别服务时，提示使用手机输入或支持语音的系统键盘。本次不引入云端 ASR 或离线模型。

## 验收

由用户安装和操作，不自行操作模拟器。

1. 真电视与手机连接同一可互通局域网，扫描后用浏览器打开，核对电视出现手机已连接，发送中文剧名后搜索。
2. 若存在多地址，验证切换后使用新二维码；关闭窗口后旧地址不能继续发送。
3. 无法访问时，反馈二维码旁 IP、手机浏览器错误以及是否为模拟器、访客 Wi-Fi 或启用 VPN。
4. 搜索页输入一段文字，点语音并取消，应保留文字；重新说出中文剧名，应只填入输入框，按搜索才开始搜索。
5. 无识别服务设备应提示原因，不能崩溃。
