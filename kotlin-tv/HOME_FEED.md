# 首页热门发现

测试版 `0.0.13-home-feed-types` / versionCode 34，分支 `feature-home-drama-feed`，Android 6+。

首页以单部作品试播替换最近播放和热门海报列表。默认漫剧，可切换真人剧。作品来自现有官网公开分类接口，播放现有详情接口中的第一集；明确标注「第一集试播」，并非官方预告或账户个性化推荐。

- 视频保持原始比例，横屏电视采用视频区加右侧剧名、集数、简介；竖屏内容不裁切。
- 视频区按上下切换作品；确定打开底部操作栏，左右选择暂停/继续、观看全集、账户收藏、漫剧、真人剧两个独立选项，当前类型以橙色粗体标记；点选当前类型不会重新加载。
- 返回先关闭操作栏，再回到顶部导航。操作栏向上可回视频区。
- 观看全集打开现有详情和选集；返回首页保留试播作品及位置。切换作品从该作品第一集开始。
- 试播结束停留当前作品，提供看全集入口；不自动换作品。错误时可重试、换剧或进入详情。
- 试播使用独立播放器与请求，不调用本机历史保存或账户进度上传。正式进入全集播放后沿用原来的历史与进度同步。
- 离开前台暂停，停止页面释放播放器及请求；返回后恢复当前试播位置。离开首页释放资源，界面内暂存状态不跨进程保存。
- 复用一个试播播放器，缓冲约 2.5～10 秒、目标 6 MB；当前视频准备好后，串行预缓冲后面 3 部第一集，每部保留最多 1 MiB 开头原始数据及解析信息，并保留上一部供回滑；不缓存整集。缓存 90 秒过期，切换类型、退出首页时清理，进入后台取消未完成预下载。缓存命中直接复用播放地址、解析结果和开头数据；首次进入、快速滑出缓存范围或缓存未完成时仍可能等待。分类按页读取，正常分页保留最多 72 部近期作品，去重并在重复页停止翻页。
- 首页试播期间暂停自动更新检查，避免播放时下载更新。更新仍可从设置手动操作。

自动化验证包括导航、位置恢复、暂停恢复、类型切换、播放结束停留、预缓冲数量上限与前后切换复用、队列去重与长期浏览容量；页面测试覆盖 API 23、26。测试使用可控数据和播放器替身，不代表实机解码与音频焦点已经验收。

人工验收由用户安装测试包：核对漫剧/真人剧加载、视频画面与声音、遥控器上下/确定/返回、账户收藏、进入全集再返回、切到其他页签/后台后是否停止播放，以及本机和账户历史是否仅记录正式播放。

离开首页时在后台关闭网络连接池，避免 HTTPS/TLS 清理触发界面线程网络异常；关闭操作幂等。回归测试覆盖清理线程及重复关闭。
