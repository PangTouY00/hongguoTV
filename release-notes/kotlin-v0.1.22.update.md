# 红果 TV 0.1.22 更新摘要

- 修复：弹窗高度按内容收缩。主题给对话框的是固定尺寸（横屏 90% 屏高），两三行的面板也撑满整屏，多出来全是空白。
- 自定义内容的面板（账号、版本与更新、云端继续观看、扫码登录、跳转集数、手机输入剧名、备份与恢复）：显示之后量出内容层的实际高度，按具体像素收窗口。上一版直接给窗口 `wrap_content` 是无效的，对话框的外层是填满窗口的布局，系统不认。
- 选项列表（全局默认清晰度、全局默认倍速、播放设置、弹幕设置）：这类用的是系统那套列表布局，装列表那一截带 `layout_weight="1"`，窗口固定高度时它被拉满，量到的就是窗口高度本身。改成把带 weight 的层放开、列表高度按已显示的每一项相加，窗口按差值收缩，按钮自然跟上来。选项没显示全时不收，免得把没测到的项裁掉。
- 开源许可、剧评长文这两处以前没接上收缩逻辑，现在接上；两处无效的 `wrap_content` 高度改成只设宽度。
- 上限仍是屏高的 86%，正文真的高过屏幕时走上限，底部按钮留在屏内。

## 怎么验证

按遥控器走一遍：账号页、「版本与更新」这类短面板应贴着内容收，不留大片空白；「全局默认清晰度」「全局默认倍速」这类选项面板的高度应等于标题加选项再加一行按钮，「取消」紧跟在选项下面；云端继续观看、扫码登录这类长内容应在上限处停住，内容能滚、按钮不被裁掉。

需要真机确认：短面板收到多小算合适、会不会显得太扁；选项列表收完之后焦点走位是否还顺；有没有哪个面板被收过头裁掉了内容或按钮。看到留白、太扁或裁掉了东西，请反馈。

覆盖安装即可，账号、收藏、观看进度与本机缓存记录都保留。
