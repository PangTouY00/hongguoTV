# 红果 TV 0.1.23 更新摘要

这一版集中修播放取址。上一版装机后是「完全无法播放」或「同一部剧有些集能播有些不能」，都不是解码问题，是取址接口被拒或回空正文。

- 服务端从 11-11 起校验真签名。我们的 x-argus 只是 base64(时间戳)，又同时发 x-gorgon / x-helios / x-medusa 这些伪造头，请求被判不可信，一律回 200 + 0 字节。新增 core/Argus.kt 生成真签名（x-argus / x-ladon / x-gorgon），签名按最终 query 重生成，占位头不再发。
- 签名改用这份注册身份构造并在会话内复用。此前 medusa 里写死的 device_id 是编译期占位身份，和 query 里的注册身份不是同一对，服务端按身份核对两者。
- 一份注册身份只放行有限几次取址：同一身份连试 8 次全空，换新身份第 1~2 次就成；串行取 20 集只有第 1 集成功。取址每一轮换一份新注册身份，cdid 不变，平台仍当同一台设备。
- 取址还要求账号身份：匿名请求 10 个 video_id 全部回 code=110001，登录后立刻能播。已登录第一轮就带账号 Cookie，被拒再退回匿名；未登录只试一轮，被拒直接显示「播放需要登录红果账号」并给登录入口，不再空转重试。
- 全档 bytevc2 的集补上官方播放器的兼容请求 codec_type=0&force_codec=h264，并把 key_seed 换成兼容响应那一份——旧 seed 解新 main_url 解不开，列表又变空。
- 选档不再预判设备能力：给最高一档真解一次，失败沿阶梯往下走并重新取址。
- 播完的集在本地记一笔，选集面板与分集网格标「已看」（灰蓝），「缓存未看 N 集」跳过它们，首页卡片写「已看完 N 集」。

本机复测：之前全空的两集，两个取址接口分别回 14.6KB / 16.0KB 完整模型，取到 1080P 与 360P。core 295 项测试通过，新增 ByteVc2FallbackTest、PlaybackAccountIdentityTest、UnplayableRenditionTest。

## 怎么验证

未登录点播放应看到「播放需要登录红果账号」；登录后点之前播不了的集应直接出清晰度；连着看下一集不应再出现「有些集能播有些不能」；看完的集在选集面板是灰蓝。这次取到的是 h265 档，若黑屏或有声无图，请把 logcat 的 `Playback address attempt:` 截给我。

覆盖安装即可，账号、收藏、观看进度与本机缓存记录都保留。
