红果 TV 0.1.9 更新说明

- 弹幕与评论现在能显示红果的表情标签：爱慕、爽、奸笑、震惊、什么、尬笑、舔屏、吃瓜、探究、送花、笑，按当前弹幕字号与文字同基线绘制；未识别的标签保留原文。插画仍为 Microsoft Fluent Emoji（MIT），非红果官方贴图。
- 手机号登录：短信能发出，但平台的验码端点不对第三方客户端签发登录会话（错误码 1），官网通道的发码又被滑块验证挡住。现在会把四个验码端点试完再判定，失败时给出平台原话并引导改用扫码登录；扫码登录实测正常，仍是推荐路径。
- 自动更新放行 GitHub 的另一个 release 资产域名，避免「更新下载地址不受支持」；检查更新与下载仍先走镜像加速、失败时回退直连。
- 兼容 Android 6.0 及以上，versionCode 50，包名与签名与 0.1.8 一致，可直接覆盖安装。

完整更新日志见本条 Release 的正文与 release-notes.md 附件。
