# 红果 TV 0.1.28 更新说明

这一版修一件事：**所有集都播不了**——首页、榜单、详情、搜索都正常，只有播放地址取不到。

## 原因

取址接口对签名头的要求变了。它要 v5 那一族 `x-khronos` / `x-helios` / `x-medusa`；带旧的 `x-argus` / `x-ladon` / `x-gorgon`，或者不签名，一律回 HTTP 200 空正文，连错误码都不给。

同一台手机、同一份新注册身份、同一个域名、同一份参数，只换签名头做四路对照：旧那一族 0 字节；不签名 0 字节；v5 三头回 22070 字节完整播放模型；v5 三头再补旧头仍然给数据。决定因素是有没有 medusa/helios。此前把这两个头停发，正是这次全空的原因。

域名（三条入口）、上报版本号（三档）都实测过，不是变量。

## 改了什么

- 取址签名改用 v5 那一族，只发 `x-khronos` / `x-helios` / `x-medusa`；GET 无正文，摘要按空内容算，不带 `x-ss-stub`。
- 取址首选 video_tab，三条入口按健康度轮换，回空的那条冷却 30 秒换下一条，不再对同一条反复撞空。
- 三条都不给结果时明确提示「播放需要登录红果账号」，界面上给「登录红果」入口。
- 排查工具进了仓库 `tools/probes/PlaybackSignatureProbe.kt`，四路对照本机不用 Gradle 就能跑；`PLAYBACK_DIAGNOSIS.md` 的取址回空一节重写，下次照它走。

## 验证

core 全量测试 318 项通过；本机走完整取址流程取到 1080P 真实地址；用户装机实测可以正常播放。GitHub Actions 的测试、lint、构建全部通过后才发布本包。

## 已知仍未解决

匿名身份在某些时段仍然全空：同一份对照代码同一天上午给数据、下午四路全空，而同一时刻已登录的 App 能正常播放。上游这个月反复开关不同请求形态与放行范围，不是改一次代码能一劳永逸的。若你未登录且三条入口都回空，界面上会提示登录。

## 怎么验证

播之前播不了的那几集，应该能出画面。若仍失败，打开设置页「诊断日志」复制出来，`Playback address attempt` 那几行会写明每条入口回了什么。

覆盖安装即可，账号、收藏、观看进度与本机缓存记录都保留。
