# 红果 TV 0.1.20 更新摘要

这一版只做界面外观，不改交互、布局和数据逻辑。

- 变更：界面底色改成一层静态深色洗底（对角渐变加两团大范围径向渐变），卡片、按钮和面板改成半透明深色面板加 1px 亮边。焦点态只把面板提亮、把边换成更亮的暖橙，不缩放不位移，卡片尺寸、网格列数和所有交互路径都不变。强调色不变。
- 修复：账号菜单、播放设置、倍速与清晰度选择、跳转集数、扫码登录、手机输入、备份与恢复、版本与更新这些弹窗，此前是系统默认的灰色面板，和界面脱节。原因是应用主题没有指定对话框主题。现在统一指定，各处创建弹窗的代码一行没改，全部自动继承深色半透明面板、1px 亮边、暖白正文与强调色按钮。
- 修复：选集按钮和排行榜名次徽标落在强调色底上时文字是白色，对比度不足 3:1，改用深色。

## 怎么验证

按遥控器走一遍首页、找剧、排行榜：底色应是带两团渐变的深色，卡片是半透明面板，焦点扫过去只变亮不变大小。再打开设置里的「登录与账户管理」、播放中的「播放设置」、倍速与清晰度选择、扫码登录：这些窗口的面板应与界面同色，不再是灰色。

大范围渐变在个别电视上可能出现色带，深色半透明面板叠在亮画面上是否够清楚，只能在真实电视上确认。看到色带、面板发灰或焦点落点不够明显，请反馈。

覆盖安装即可，账号、收藏、观看进度与本机缓存记录都保留。
