# 红果 TV 0.1.20

版本：`versionName 0.1.20` / `versionCode 61`，支持 Android 6.0 及以上（minSdk 23）。覆盖安装即可，收藏、观看进度、本机缓存记录都保留。

这一版只做界面外观：不改任何交互、布局、焦点跳转、数据逻辑或接口。

## 变更：界面改用深色渐变洗底与半透明卡片

界面底色从单一深色改成一层静态洗底：对角线性渐变打底，左上与右下各叠一团大范围径向渐变（偏紫灰与偏钢蓝）。洗底每次建屏时构造一次，不随焦点变化、不做动画，播放时不产生任何逐帧开销。

卡片、按钮和面板改成半透明深色面板加 1px 亮边，叠在这层底色上。焦点态只把面板提亮、把边换成更亮的暖橙，不缩放、不位移——卡片尺寸、网格列数、焦点跳转和所有交互路径都与上一版一致。强调色仍是原来的珊瑚橙。

没有运行时模糊：正式包面向的盒子低于 Android 12，`RenderEffect` 是 API 31，所以这里的毛玻璃感来自半透明面板叠在渐变上，不是真模糊，也没有预生成模糊位图。播放界面仍是纯黑背景，只在底部保留原有的半透明黑色渐变托住标题和状态行；暂停图标与登录二维码仍是白底，它们分别叠在视频画面和扫码器上。

顺带修了一处一直存在的老问题：选集按钮和排行榜名次徽标落在强调色底上时，文字原来是白色，在橙底上对比度不足 3:1，现在改用深色。原先散在多个界面文件里的硬编码色值全部改读 `TvStyle`。

## 修复：弹窗不再落到系统灰色面板

账号菜单、播放设置、倍速与清晰度选择、跳转集数、扫码登录、手机输入剧名、备份与恢复、版本与更新这些弹窗，此前都是系统默认的灰色面板。原因是应用主题没有指定对话框主题，`AlertDialog` 于是继承系统 Material 的默认样式，和界面脱节。

现在在主题里统一指定对话框样式，各处创建弹窗的代码一行没改，全部自动继承：面板换成深色半透明加 1px 亮边、12dp 圆角，与卡片同一套语言；正文用暖白、次要文字用灰蓝、按钮沿用强调色。正文对面板约 14:1，次要文字约 6:1。弹窗里由代码构造的说明文字也改用界面同一组取色，不再硬编码白色。

配色集中到两处：`TvStyle` 供代码里动态绘制的控件，`res/values/colors.xml` 供主题与面板 drawable，两处是同一组值并互相指认。以后调配色只改这两处。

## 怎么验证

装上之后按遥控器走一遍：首页、找剧、排行榜的底色应当是带两团渐变的深色，卡片是半透明面板；焦点扫过去只变亮不变大小。然后打开设置里的「登录与账户管理」、播放中的「播放设置」、倍速与清晰度选择、扫码登录，这些窗口的面板应当与界面同色，不再是灰色。

需要说明的是，大范围渐变在个别电视上可能出现一圈一圈的色带，深色半透明面板叠在亮画面上是否够清楚，这两件事只能在真实电视上确认。如果你看到色带、面板发灰或者焦点落点不够明显，请反馈，下一版调。

## 安装与更新

- 下载本页附件 `hongguotv-kotlin-0.1.20-android6.apk`，覆盖安装。
- App 内「检查更新」读的是本仓库标记为 Latest 的正式 Release，附件同时带 `update.json`（含包名、版本、大小与 sha256）。
- 这一版没有改动账号、收藏、观看进度的存储格式，升级后直接沿用。
