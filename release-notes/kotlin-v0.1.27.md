# 红果 TV 0.1.27

版本：`versionName 0.1.27` / `versionCode 68`，支持 Android 6.0 及以上（minSdk 23）。覆盖安装即可，账号、收藏、观看进度与本机缓存记录都保留。

这一版做三件事：首页上停着不动会自动把当前这部播起来；从首页进全屏那段过渡不再留下黑屏；画面模式加一个「裁剪铺满」，放大倍数改成滑杆可调 1.0—2.0。

## 一、首页没有操作满 20 秒，自动进入全屏播放

**这条要解决什么。** 在首页上用方向键连着换了几部剧，试播跟着换，换到想看的就停下了——但还要再按一次确认才播得起来。遥控器就在手边，人常常就停在那儿。

**触发条件。** 从最后一次按键或触摸起算，满 20 秒没有任何操作，就自动进入全屏播放当前显示的这部（`core/AutoFullscreen.kt` 的 `AutoFullscreenGuard`，默认 `idleMs = 20_000`）。这条最早是按「焦点停在同一部作品上满 30 秒」算的，实机上不对：真正想要的是「切了剧却没有继续操作」，不是焦点停了多久。所以改成按用户活动计时——任何按键、触摸都把当前这一部的计时重新开始，也不再要求焦点落在那块预览上、不要求试播已经就绪。

**什么时候不算。** 自己从全屏返回过、按过暂停、或打开过操作面板之后，这一部不再被自动拽回；换到别的作品照常重新计时。首页上任何按键、触摸，以及界面 pause 都会取消当前计时。

**进去之后播哪儿。** 屏幕上正在试播的就是要播的那一部那一集，起播位置接着试播停下的那一秒（`openDetail` 的 `fromTrial`），不读本机或云端的观看进度，也不据此去挑「上次看到」的那一集。本集播完仍按「自动连播」接下一集正片。自动进入的全屏按返回回到首页，不落中间的详情页。

**顺带修的一处。** 首页第一行再按一次 ↑ 现在能把焦点交回顶部导航。原来 `topHintShown` 从未被置位，顶部导航到不了。

## 二、进入全屏这段等待期不再出现黑屏

自动进全屏这条路径会先盖一层封面做过渡，它有三处会留下黑屏：

1. 过渡层的封面走的是按页绑定的取图（`loadCover` → `ArtworkLoader.load`）。`openDetail` 之后建播放器那一步会做换页清理（`playEpisode` 里的 `artwork.cancelPage(clearMemory = true)`），把过渡层的封面连同它的请求一起清掉，此后再不会填回来，屏幕上只剩这层黑底。
2. 这一层写死「2.5 秒后自行交出去」。读详情、签名播放地址、起解码器实测要一到三秒，常常比它更慢，于是先撤掉封面、再对着还没有画面的播放器等。
3. 取详情失败、播放失败时没有撤掉这一层，错误说明与「立即重试」都被盖在黑底下。

改法：

- 封面改用不受换页取消的取图入口（`ArtworkLoader.requestBitmap`：这条取图不属于任何一页，换页不取消它，取到的位图直接交回调用方），并在自动进入全屏前三秒先把它取好（`HomeFeedScreen.coverLeadMs = 3_000`，预热与真正使用同一个尺寸），进入那一刻遮罩上就是现成的画面。
- 这段等待期的时间安排集中到 `core/FullscreenHandoff.kt`：封面先到就用封面到达那一刻；封面迟迟不来，最迟 900 毫秒（`coverGraceMs`）也给出这一层并写明还在准备这一集；提示文字在没有封面时 700 毫秒后出现（`hintAfterMs`），有封面时 3 秒（`hintWithCoverAfterMs`）；画面没出来就不撤这一层；取详情失败、播放失败、或到 20 秒上限（`giveUpAfterMs`）仍无画面，立刻撤掉，让错误说明与播放界面的进度露出来。`MainActivity` 在两条失败路径上调 `playbackTransition.cancel()`。
- 还有一处更隐蔽的：这一层摘不掉。`addContentView` 把它加的位置不是 `decorView` 本身，而是它内部那个 `@android:id/content` 容器，而 `ViewGroup.removeView` 只认自己的直接子 view，所以 `finish()` 与 `cancel()` 里的 `decor.removeView(host)` 什么都摘不掉。这一层带着不透明的黑底，会一直留在屏幕上，把视频连同播放界面的标题、进度、错误说明一起盖住——表现就是「海报出现 → 纯黑、只有声音没有画面」，屏幕上连一个字都看不到。只有从首页自动进全屏这条路径会创建它（`from != null` 才 `start`），所以从详情页点播放等其它入口一切正常。现在摘除只认这个 view 自己的 parent，不去猜它挂在哪一层。
- `finish()` 原先只把封面淡到透明、把这层的黑底留在原地，淡出的那 180 毫秒里必然是一段纯黑；现在整层一起淡出，画面从封面底下露出来。

过渡本身只动封面图（从卡片位置放大铺满，260 毫秒），播放器不参与缩放与淡入：`SurfaceView` 的视频内容不跟随普通 View 变换，Media3 在 Android 6/7 上因缩放 PlayerView 出过现网问题（androidx/media #1664、#3070），本包 minSdk 23。

## 三、画面模式：裁剪铺满，放大倍数滑杆可调

**裁剪铺满。** 新增一种模式：保持画面比例、把它填满屏幕，超出屏幕的部分裁掉，不变形、不留黑边。这一档直接交给 Media3 已有的 `AspectRatioFrameLayout.RESIZE_MODE_ZOOM`——ExoPlayer 在 [issue #5152](https://github.com/google/ExoPlayer/issues/5152) 里给的用法就是切这个 resizeMode，不自绘缩放路径。四种模式现在对应：完整画面与自定义放大 → `RESIZE_MODE_FIT`（放大是 view 缩放），裁剪铺满 → `RESIZE_MODE_ZOOM`，拉伸铺满 → `RESIZE_MODE_FILL`。它和自定义放大的区别是：裁剪铺满总是正好铺满屏幕，裁掉多少由画面比例决定；自定义放大是你能控制裁多少。

**1.36 倍改成 1.0—2.0 可调。** 原来「放大 1.36 倍」是写死的。现在这一行叫「自定义放大」，倍数存在设置里（`BackupSettings.frameZoom` 与 `frameZoom` 键），只允许 1.0—2.0 之间 0.1 的整档。倍数内部按十分之一记（10…20）：0.1 在二进制里不精确，直接在浮点上加减会把档位落到 1.5000001 这种半档上，加减与端点判定都在整数上做。旧版本存的 1.36 读回来收到最近的 1.4；旧备份与旧磁盘记录都不会报错——读旧备份得用 `opt`，`get` 对缺失的键直接抛 `JSONException`，这条是测试跑出来的。

**滑杆是给遥控器用的。** [SeekBar 的 API](https://developer.android.com/reference/android/widget/SeekBar) 本来就写了可以用方向键，`setKeyProgressIncrement` 就是给按键设步长的官方开关；但 Android TV 上默认步长按控件宽度算、各家 ROM 表现不一，所以显式设成 1 格（`max = 10`）：遥控器一次按键正好 0.1 倍。焦点落在「自定义放大」那一行上时，左右键同样调档；触屏可以直接拖。

**调的就是眼前这一帧。** 焦点落到哪一行，画面立刻变成哪一行；滑到哪一档，画面立刻跟着变——裁剪与放大这种效果，只有边调边看才判断得出来。确认键保留当前这一项，返回或「返回并恢复」退回打开面板之前的模式与倍数。预览不写盘，免得每按一次都改一次持久化设置。

**电视上的排版。** 倍数数值单独占一行、1.0 与 2.0 贴在滑杆两侧。原来那种固定宽度的数值块在 720p 与 1080p 的电视上差一倍的 density，挤在滑杆旁边会被截断。

## 验证

新增 22 项 core 单测，同时删掉 1 项旧语义的计时用例：`AutoFullscreenTest` 9 项覆盖到点、用户活动重新计时、主动离开的压制与换作品复位、跨实例保留，并断言默认时长是二十秒；`FullscreenHandoffTest` 9 项覆盖封面早到／晚到、提示的两档时机、画面未出不撤、失败与上限立刻撤、默认时间值；其余 4 项覆盖放大档位的加减与端点（十次按键正好从 1.0 走到 2.0、端点不反弹）、NaN 与正负无穷、旧值 1.36 收敛到 1.4、备份往返与磁盘缺字段时取默认值。core 346 项全部通过，app 全量源码编译 0 错误。面板的焦点与按键行为属于 view 层，本仓库的 app 测试是纯 JVM、没有 Robolectric，本机测不到。

GitHub Actions 运行 `:core:test`、`:app:testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`、`:app:assembleRelease`，全部通过后才发布本包。

## 怎么验证

1. 首页上翻几部剧然后不动手，满 20 秒应自动进入全屏，位置接着刚才试播的那一秒；按返回应直接回首页，不落详情页。
2. 中途主动按过返回或暂停之后，这一部不该再被自动拽回；换一部照常重新计时。
3. 自动进全屏时看有没有黑屏：应该是封面 → 画面，中间不出现纯黑、也不出现「只有声音没有画面」。这一段只能实机看，本机的测试覆盖不到 view 层。
4. 播放设置 → 画面：四行都在，上下键走行，焦点到哪一行画面立刻变；走到「自定义放大」时左右键一次 0.1 倍，到 1.0 与 2.0 停在端点不反弹；按确认保留，按返回退回原模式与原倍数。
