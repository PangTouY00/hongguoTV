# 红果账号与同步

当前原生客户端支持红果官方扫码登录、账户观看历史、账户预约和相关作品入口。本机记录与账号记录分开保存；账号缓存按当前会话隔离，退出或切换账号后立即清空旧账号资料。

## 登录

- 已验证的路线为电视显示二维码，手机红果 App 扫码并确认。
- 手机号短信入口保留，但平台滑块验证和会话校验可能阻断登录；收到短信不代表已取得有效登录态，不应反复自动发送或提交验证码。
- 取得会话后必须通过红果账号资料验证，再保存登录态。
- 登录态用 Android Keystore AES-GCM 加密保存，独立于本机片单备份；不记录密码、验证码、Cookie 或令牌。
- 不以模拟器提取或导入凭据替代电视直接登录。

## 观看历史

- 「最近观看」是本机记录；「账户观看历史」读取当前账号云端最近 50 部记录。
- 本机续播采用本机进度，账户历史续播采用云端集数和时间。
- 云端历史不会批量导入本机；实际在电视播放才产生本机观看记录。
- 电视定期及暂停、退出时请求上传播放进度。不能把接口接受上传等同于手机端逐集、逐秒双向续播已完整验收。
- 红果收藏同步尚未实现，现有收藏属于本机。

## 预约

账户预约分别读取已上线、待上线，每类目前读取最近 20 部。待上线使用平铺字段，与已上线的嵌套剧集资料不同，不能套用同一种解析。用户已核对已上线 9 部、待上线 11 部均显示正常。

详情页相关作品可打开其他季，待上线提供预约入口。提交请求被接受和账户列表确认是不同状态；只有列表确认后才显示已预约。相关协议与手动验收见 [相关作品说明](../kotlin-tv/RELATED_WORKS.md)。

## 排查注意

扫码成功但电视仍未登录曾由 Android 的异步 OnDismiss 回调造成：保存任务受 busy 状态阻挡而被跳过。主动结束二维码操作时须先解除关闭监听、同步结束当前操作，再启动保存任务；延迟的关闭回调不能取消后继任务。

账户接口、登录态加密及异步会话隔离的更多要点见 [开发排查笔记](DEVELOPMENT_NOTES.md)。旧版本调试流水已清理，必要时通过 Git 历史追溯。
